## Spec Kit, Superpowers et Claude Code Game Studios

Consulter [AGENTS.md](AGENTS.md) et le
[guide des outils IA](.ai-tools/README.md).
Utiliser Spec Kit pour le cadrage, Superpowers pour les pratiques de
développement pertinentes et Claude Code Game Studios pour l'expertise jeu
lorsqu'elle s'applique à la tâche.

Réutiliser une installation Claude existante avant d'en préparer une autre.
Conserver les réglages, hooks, instructions et documents du projet ; intégrer
seulement les outils nécessaires. Les plugins et commandes doivent être
disponibles dans la session avant d'être invoqués.
